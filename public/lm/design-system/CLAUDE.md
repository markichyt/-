# CONSULTANT design system

Эта папка — дизайн-система CONSULTANT Legal Marketplace. Любая работа в этой папке или «в стиле CONSULTANT» делается по `DESIGN-SYSTEM.md` (правила) и `components.md` (разметка), с `tokens.css` + `styles.css` для веба и `tokens.json` для всего остального.

Ключевые правила: чёрный/белый/серый; #0095D4 только на главной кнопке, точках логотипа и live-точке (≤ 5% площади, без оттенков); Manrope для заголовков, Onest для текста; фото с острыми углами, карточки 24–28 px, кнопки-пилюли; секции 120 px, контейнер 1200; одна главная кнопка на экран; никаких градиентов, теней, эмодзи и выдуманного текста.

Эталон: `templates/home.html`, скриншот `examples/home-approved-A-images-sharp.png`. Чек-лист перед сдачей: `DESIGN-SYSTEM.md` §11.
