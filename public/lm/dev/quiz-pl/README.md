# Квізи ConsultantLM — Польща (pl, consultant.net.pl)

Чистий HTML, CSS і JS (ES5, без збирання): файли можна правити й викладати як є. Код не мінімізований,
змінні названі зрозуміло, коментарі в коді — українською та російською (як писалися під час розробки).

## Сторінки

| Файл | Що це |
|---|---|
| `index.html` | Основний квіз-воронка «Аналіз ситуації»: 16 екранів від входу до встановлення застосунку |
| `dynamic.html` | Динамічний квіз «Підбір юриста»: маршрут залежить від відповідей |

## Структура

```
index.html, dynamic.html   розмітка всіх екранів
css/tokens.css             змінні дизайн-системи: кольори, шрифти, відступи, радіуси
css/base.css               кнопки, поля, чипи, картки дизайн-системи
css/quiz.css               оболонка квізу й усі екрани (спільний для обох сторінок)
js/config.js               налаштування локалі для обох сторінок — window.QUIZ_LOCALE
js/quiz.js                 логіка основного квізу (index.html)
js/dynamic.js              логіка динамічного квізу (dynamic.html)
assets/app/                ролики екрана S0 і встановлення застосунку (mp4 + webm + постер)
assets/people/             фото фахівців (назви файлів — із даних у js/config.js)
assets/geo/                контури країн для карти на S3 (вантажаться за кодом країни)
assets/logo/, assets/fonts/  логотипи та шрифти бренду
assets/vendor/             jQuery, jquery.mask, компонент телефону — сторонній код, не правити
```

Стилі підключаються в `<head>` саме в цьому порядку: Google Fonts → `tokens.css` → `base.css` → компонент телефону → `quiz.css`.
Скрипти — наприкінці `<body>`: `config.js` (у `<head>`), jQuery, маска, компонент телефону, потім `quiz.js` або `dynamic.js`.

## Іменування — БЕМ

`блок__елемент--модифікатор`: `funnel__screen`, `funnel__screen--entry`, `plan__savings-total`.
Стан — окремий клас `is-…`/`has-…` або атрибут `data-state`.

Основні блоки: `funnel` (оболонка, шапка, нижня панель «Назад / Далі»), `q-…` (варіанти, поля, помилки),
`plans`/`plan` (слайдер пакетів), `appframe` (екран застосунку з відповідями), `mq` (бігучі ряди фахівців), `progress`.

## Як влаштований JS

Кожен скрипт — одна самовикликана функція. Допоміжні: `qs(selector, root)` і `qsAll(...)` — querySelector,
`escapeHtml`, `announce` (оголошення для екранних читачів), `track` (аналітика).

- **Екрани.** Поточний екран — у `location.hash` (`#s0`, `#s1`…; у динамічному — `#start`, `#category`…).
  Перехід — `go(id, dir)`, відмальовка — `render(id)`. Кнопки нижньої панелі описані в `BAR`, умови «можна далі» — у `GATE`.
  У динамічному квізі маршрут і кнопки — в об’єкті `FLOW`, питання — у `QUESTION`.
- **Стан** — лише в пам’яті (`state`): повторний вхід починає квіз спочатку.
- **Аналітика.** `track(eventName, extra)` пише подію в `window.dataLayer` і шле `CustomEvent('ds:quiz')`.
  Події: `quiz_start`, `quiz_step_view`, `quiz_step_complete`, `quiz_contact_submit`, `membership_select`,
  `checkout_view`, `checkout_submit`, `payment_success`, `payment_failed` та ін. UTM-мітки зберігаються з першого екрана до ліда.
- **Лід — заглушка.** Бекенду немає: у `js/quiz.js` блок «S12 · контакти» створює лід і пише його в консоль
  (`[quiz] lead + question created`), у `js/dynamic.js` — `[quiz-dynamic] lead created`. Сюди підключається API.
  Оплата на S13 — імітація: у продукті тут має бути наявний checkout.
- **Тексти інтерфейсу** — у розмітці та в рядках скриптів (уже перекладені на мову локалі).
  Дані (пакети, ціни, фахівці, кейси, міста, рейтинги) — у `js/config.js`.

## Екрани основного квізу (`index.html`)

| Екран | Що на ньому |
|---|---|
| `s0` | Вхід: ролик застосунку, що отримає людина, кнопка старту |
| `s1` | Як підбираються фахівці: лічильник, бігучі ряди фото, критерії |
| `s2` | Місто з підказками або «дистанційно» |
| `s3` | Карта з точкою міста, скільки фахівців поруч |
| `s4` | Напрям права (кілька плиток) |
| `s5` | Приклади справ за напрямом |
| `s6` | Питання: заголовок 7–12 слів, опис від 50 символів. **Голосового повідомлення немає** |
| `s7` | «Вже аналізуємо»: кроки обробки й анімація відповідей у застосунку |
| `s8` | Відповіді фахівців трьох рівнів |
| `s9` | Чого людина хоче далі |
| `s12` | Контакти: ім’я, телефон із маскою країни, згода → лід |
| `s15` | «Дякуємо» й пропозиція VIP-пакета |
| `s11` | Вибір пакета: BASE / PRO / PREMIUM, місяць або рік (−10 %), приклад економії |
| `s13` | Оплата (імітація) |
| `s14` | Успішна оплата |
| `s16` | Встановлення застосунку: кроки, кнопки магазинів, ролик |

Гілка «Продовжити без VIP» з `s15`/`s11` веде одразу на `s16`.

## Перевірка

Відкрийте `index.html` через будь-який локальний сервер (наприклад, `python3 -m http.server` у цій папці)
і пройдіть квіз. Карта на S3 підвантажує `assets/geo/<КОД>.json` — з `file://` деякі браузери це блокують.
